# Local Ops 1.9.0

[简体中文](#简体中文) · [English](#english)

## 简体中文

Local Ops 1.9.0 新增 Intel（`x64`）macOS 安装包支持，并移除对 Docker Desktop 的硬依赖，改为兼容任何 Docker CLI 运行时。

### 主要更新

- 同时提供 `arm64`（Apple Silicon）和 `x64`（Intel）两个 DMG 安装包。
- 构建脚本自动检测宿主架构，支持通过 `LOCAL_OPS_BUILD_ARCH` 和 `LOCAL_OPS_KEYCHAIN_ARCH` 环境变量覆盖。
- Docker 功能兼容任何 Docker CLI 运行时（Docker Desktop、Colima、OrbStack、Rancher Desktop、Podman 等），不再自动拉起 Docker Desktop。
- 移除托盘菜单和 Web 控制台中的"启动 Docker Desktop"按钮，Engine 离线时提示用户自行启动运行时。
- 会话恢复在 Engine 离线时跳过 Docker 恢复并告警，不再自动打开 Docker Desktop。

### 安装与升级

从 [Releases](https://github.com/Arvinnma/local-ops-console/releases/latest) 下载 `Local-Ops-1.9.0-arm64.dmg`（Apple Silicon）或 `Local-Ops-1.9.0-x64.dmg`（Intel），打开后把 **Local Ops** 拖到"应用程序"。

升级会保留 `catalog.json`、`last-session.json`、本机 API 密钥和钥匙串项目。替换 App 会重载内置后台，重要传输结束后再升级。

## English

Local Ops 1.9.0 adds Intel (`x64`) macOS package support and removes the hard dependency on Docker Desktop in favor of any Docker CLI-compatible runtime.

### Highlights

- Ship both `arm64` (Apple Silicon) and `x64` (Intel) DMG packages.
- Build scripts auto-detect the host architecture and support overrides via `LOCAL_OPS_BUILD_ARCH` and `LOCAL_OPS_KEYCHAIN_ARCH` environment variables.
- Docker features work with any Docker CLI-compatible runtime (Docker Desktop, Colima, OrbStack, Rancher Desktop, Podman, etc.); Local Ops no longer launches Docker Desktop automatically.
- Remove the "Start Docker Desktop" button from the tray menu and web console; when Engine is offline, users are prompted to start their own runtime.
- Session restore skips Docker restoration and warns when Engine is offline instead of auto-launching Docker Desktop.

### Install and upgrade

Download `Local-Ops-1.9.0-arm64.dmg` (Apple Silicon) or `Local-Ops-1.9.0-x64.dmg` (Intel) from [Releases](https://github.com/Arvinnma/local-ops-console/releases/latest), open it, and drag **Local Ops** to **Applications**.

Upgrades preserve `catalog.json`, `last-session.json`, the local API token, and Keychain items. Replacing the App reloads the bundled backend, so finish important transfers before upgrading.
